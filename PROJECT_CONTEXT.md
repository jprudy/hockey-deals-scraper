# HockeyDeals.ca Rebuild

This is a Canadian hockey deals aggregation website.

Goal:
Build a fast, scalable platform to replace WordPress.

Core features:
- Deals listing
- Filters (category, brand, price, size)
- Deal detail pages
- Admin panel
- CSV import system
- SEO pages

Stack:
- Next.js (App Router)
- TypeScript
- Tailwind
- Prisma
- PostgreSQL

Important:
- Mobile-first
- SEO-friendly
- Fast performance
- Scalable for future niches (Outdoor, Cosmetics)
